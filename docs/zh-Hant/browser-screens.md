# 瀏覽器螢幕（平板、手機）

> **新功能，實驗性。** 你網路中的任何瀏覽器都能全螢幕顯示 Kiosko 的螢幕：牆上的舊平板、桌上閒置的手機。
> 不必購買硬體，也不需要韌體：開啟一個網址，在編輯器中輸入代碼，就完成了。
> 使用 Kiosko 自有韌體的 Wi-Fi 小螢幕，請參閱 [remote-screens.md](remote-screens.md)。

你會得到：

- **以代碼配對。** 瀏覽器顯示 6 位數代碼，你在編輯器中輸入。只有你配對過的瀏覽器才會收到畫面，而且傳輸經過加密。
- **跟隨裝置。** 螢幕採用瀏覽器視窗的尺寸，平板旋轉時隨之旋轉。
- **自動恢復。** 平板休眠、Wi-Fi 中斷或頁面重新載入後，它會自動重新連線而不必重新配對，並立刻顯示目前的畫面。
- **編輯器維持私密。** 瀏覽器連線的是另一個只提供螢幕頁面的小型伺服器；編輯器仍只在這台電腦上監聽。

## 開啟網路螢幕

網路螢幕預設為關閉，需要你自行開啟。在編輯器的**螢幕**頁面底部找到**網路螢幕（瀏覽器）**。開啟後選擇：

- **監聽**：「區域網路」（所有網路介面，通常選這個）、「僅限本機」（用於以 USB 線連接的平板，請見[有線模式](#有線模式以-usb-連接的-android)），或本機的某個位址。
- **連接埠**：7429，除非已被佔用。

接著卡片會顯示要開啟的網址（本機每個網路介面一個）及其 QR 碼。

在設定檔中是這樣：

```json
"networkScreens": { "enabled": true, "host": "0.0.0.0", "port": 7429 }
```

防火牆必須允許平板連到該連接埠（在 Windows 上，詢問時請允許 Node.js 存取私人網路）。

## 新增瀏覽器

1. 在平板或手機上開啟編輯器顯示的網址，例如 `http://192.168.1.20:7429/`（或掃描 QR 碼）。頁面會顯示一個大大的 6 位數代碼，下方是瀏覽器的類型及其 ID 的 4 個字元。
2. 在編輯器中：**螢幕 → 新增螢幕 → 瀏覽器（平板、手機…）**。會列出等待配對的瀏覽器，以及它們的尺寸和位址。
3. 選擇你的瀏覽器（若只有一個在等待，則已自動選取），輸入它的代碼。錯誤的代碼會被拒絕，瀏覽器會顯示新代碼，下一次嘗試需要稍等一下（每輸錯一次等得更久）。
4. 會出現一個新螢幕，尺寸與瀏覽器相同，並帶有第一個頁面。像編輯其他螢幕一樣編輯它即可。

輕觸頁面進入全螢幕。在任何位置長按（或輕觸右上角）開啟選單：全螢幕、取消配對。

若要把瀏覽器配對到現有螢幕而不是新螢幕，請在該螢幕的卡片上使用**重新配對**。

沒有瀏覽器顯示某個螢幕時（分頁已關閉、平板休眠或離開網路），Kiosko 不再為它繪製任何內容，就像拔掉的面板一樣；瀏覽器回來時會立刻收到一幅新畫面。

## 尺寸與方向

開啟**跟隨瀏覽器的尺寸**（預設）時，螢幕採用瀏覽器視窗以裝置像素計的尺寸（長邊最多 1920），並在裝置旋轉時於橫向和直向之間切換，頁面會像旋轉任何面板時一樣重新排版。細微的變化（網址列出現又消失）會被忽略。關閉它可以保留你自己設定的尺寸：瀏覽器會把畫面盡可能放大顯示。

## 保持螢幕常亮

除非頁面要求，瀏覽器會讓螢幕休眠。頁面會盡力而為：

- **Wake Lock**，在瀏覽器允許的情況下：僅限安全頁面（`https` 或 `http://127.0.0.1`，請見[有線模式](#有線模式以-usb-連接的-android)）。`http://192.168.x.x` 上的頁面不屬於安全頁面。
- 其他情況下，播放一段**極小的靜音影片**，持續播放可以讓大多數行動瀏覽器保持喚醒。有些瀏覽器不承認靜音影片：這時請使用下面的方法之一。

頁面的選單會顯示目前起作用的是哪一種。以下方法更可靠，與瀏覽器無關：

- 裝置本身的設定：把螢幕逾時設為最長；在 Android 上，「開發人員選項 → 保持清醒」可在充電時讓螢幕保持開啟。
- **Kiosk 瀏覽器 App**（Android 上如 Fully Kiosk Browser；iPad 上用「引導使用模式」並把「自動鎖定」設為「永不」）：全螢幕、保持常亮、開機自動啟動。把它指向頁面的網址即可。
- 把頁面加入主畫面，開啟時就不會顯示瀏覽器的工具列。

## 有線模式（以 USB 連接的 Android）

以 USB 線連接的 Android 平板完全不需要網路就能連到 Kiosko，而且是作為安全頁面（因此 Wake Lock 可用）：

1. 在平板上啟用「開發人員選項 → USB 偵錯」；接上線並允許這台電腦。
2. 在編輯器中，把網路螢幕設為監聽**僅限本機**（`"host": "127.0.0.1"`）：不會向網路暴露任何內容。
3. 在電腦上執行 `adb reverse tcp:7429 tcp:7429`。
4. 在平板上開啟 `http://127.0.0.1:7429/`，依上文方法配對。

`adb reverse` 在拔掉線或平板重新啟動之前都有效：之後需要重新執行（可以用一個小指令碼或 udev 規則自動完成）。

## 安全性

網路螢幕伺服器向你網路中的任何人公開的內容：

- 檢視器頁面（其 HTML、指令碼、樣式和圖示）；
- 一個 WebSocket，瀏覽器透過它證明自己持有配對金鑰，或顯示代碼等待配對。

其他請求一律回應 404。它是一個獨立的伺服器，而不是權限較少的編輯器伺服器：它沒有通往編輯器、編輯器 API、設定、記錄或外掛的路由，編輯器仍只在 127.0.0.1 上監聽。

瀏覽器如何取得信任：

- **配對**使用 SPAKE2（與 ESP32 螢幕相同），以瀏覽器顯示的代碼為基礎：必須有人從螢幕上讀出代碼並在編輯器中輸入。錯誤的代碼不會洩漏任何資訊，會讓瀏覽器產生新代碼，並讓下一次嘗試等待（5 秒，逐次加倍，最多一分鐘）。
- **工作階段**：每次連線時，雙方都以新的 nonce 證明自己持有金鑰，之後每則訊息都以為該連線產生的金鑰用 ChaCha20-Poly1305 加密封裝。沒有有效金鑰的瀏覽器收不到任何畫面；無法解開的訊息會結束工作階段。
- **限制**：同時最多 32 個連線，每個位址 4 個 WebSocket，8 個等待中的瀏覽器，瀏覽器送來的每則訊息最大 4 KB；其他網站的頁面無法開啟該 WebSocket。
- **撤銷**：螢幕卡片上的「撤銷」會從設定中刪除金鑰，並通知瀏覽器忘記它；瀏覽器會重新顯示代碼。頁面選單中的「取消配對」在平板上做同樣的事。

它無法防範的情況：

- 頁面以一般 HTTP 提供：能竄改你區域網路流量的人，可以向平板提供被修改過的頁面。使用有線模式或你信任的網路可以避免這一點。
- 配對金鑰儲存在瀏覽器的儲存空間中：拿到已解鎖平板的人可以複製它。平板遺失時請撤銷它。
- 你網路中的任何人都能開啟該頁面，裝置也可能把自己加入等待中的瀏覽器清單；但配對仍然需要*你的*平板上顯示的代碼。輸入之前請核對位址和那 4 個字元。

## 疑難排解

- **頁面打不開**：卡片上是否顯示「已開啟，連接埠 7429」？平板是否在同一個網路，防火牆是否放行？試試卡片上列出的其他位址。
- **清單中沒有瀏覽器**：頁面必須處於開啟狀態並顯示代碼。開著頁面休眠的平板會在半分鐘後從清單中消失；喚醒它即可。
- **平板休眠時畫面停止**：請見[保持螢幕常亮](#保持螢幕常亮)。平板喚醒後會自動恢復。
- **正常運作後又回到代碼畫面**：螢幕已被撤銷或在 Kiosko 中被刪除，或瀏覽器的儲存空間被清除了。重新配對即可。

訊息定義在 [packages/core/src/browser/protocol.ts](../../packages/core/src/browser/protocol.ts) 中：即遠端螢幕通訊協定（[remote-screen.md](../remote-screen.md)）的訊息，承載於 WebSocket 上，由瀏覽器發起連線並先發言。
