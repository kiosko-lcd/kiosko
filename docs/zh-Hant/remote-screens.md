# Wi-Fi 螢幕（ESP32）

> **新功能，實驗性。** Kiosko 也能驅動使用 ESP32 的 Wi-Fi 小螢幕，執行 Kiosko
> 自己的開放韌體。它們像任何面板一樣顯示 Kiosko 的螢幕，可以放在家中任何地方。
> 本指南說明如何使用；通訊協定請見 [remote-screen.md](../remote-screen.md)。

你會得到：

- **自動宣告自己。** Kiosko 會自行在你的網路上找到它。
- **以螢幕上的代碼配對。** 只有站在螢幕前的人才能配對，連線也經過加密。
- **自動重新同步。** 拔掉電源或 Wi-Fi 中斷後，Kiosko 會重新連上，並在它回來時立刻送出目前的畫面。
- **任何方向**，直立或橫放，在 Kiosko 中設定。
- **可同時使用多台**，每台有自己的名稱和頁面。

## 需要什麼

- 支援的開發板。目前：**Waveshare ESP32-C6-LCD-1.47**（172×320）。之後會支援更多；韌體已為此保留開發板層。
- 一條 USB-C 線，用來安裝一次韌體。之後透過 Wi-Fi 更新。
- 與執行 Kiosko 的電腦共用的 2.4 GHz Wi-Fi 網路，兩者之間允許多點傳播（mDNS）。

## 安裝韌體

**現成映像檔。** [GitHub](https://github.com/kiosko-lcd/kiosko/releases/latest)
上的每個 Kiosko 版本都附有以下檔案及其 SHA-256：

- `kiosko-screen-<版本>-waveshare-esp32c6-lcd-1.47-full.bin`：完整的快閃記憶體，透過 USB 寫入新開發板。會清除開發板上原有的內容。
- `kiosko-screen-<版本>-waveshare-esp32c6-lcd-1.47.bin`：只有應用程式，用於從 Kiosko 或螢幕的設定頁面更新。

寫入完整映像檔時，接上開發板，並在 Docker 中使用 `esptool`（不必安裝任何東西）：

```sh
docker run --rm -v "$PWD:/w" --device /dev/ttyACM0 espressif/idf:v5.5.5 \
  esptool.py --chip esp32c6 -b 921600 write_flash 0x0 /w/kiosko-screen-0.1.1-waveshare-esp32c6-lcd-1.47-full.bin
```

請使用開發板實際出現的連接埠（Linux 上可用 `ls /dev/serial/by-id/` 查看）。其他 `esptool` 或 Espressif 的網頁燒錄工具也可以。

**自行編譯。** 在 [firmware/esp32-screen](../../firmware/esp32-screen) 中，一切都在 Docker 裡執行：

```sh
./idf build           # build/kiosko_screen.bin
./idf flash           # 透過 USB
./idf backup old.bin  # 先備份開發板目前的快閃記憶體
```

**Linux 的 USB 權限。** 你的使用者必須能開啟序列埠。加入 `dialout` 群組後重新登入：

```sh
sudo usermod -aG dialout "$USER"
```

## 第一次啟動與 Wi-Fi

若沒有儲存 Wi-Fi，或 20 秒內無法連線，螢幕會開啟自己的網路 `Kiosko-<名稱>-setup`，並在螢幕上顯示密碼。

1. 用手機或筆電連上該網路。
2. 設定頁面會自動開啟；若沒有，請前往 `http://192.168.4.1`。
3. 選擇你的 Wi-Fi 網路並輸入密碼。也可以在這裡為螢幕命名（`a-z`、`0-9`、`-`）並設定時區。
4. 儲存。螢幕會重新啟動並加入你的網路，接著顯示它的名稱、位址，以及「尚未配對：在 Kiosko 中加入」。

## 在 Kiosko 中加入

任選一種方式：

- **編輯器。**「螢幕 → 新增螢幕 → 偵測面板」。螢幕會出現在清單中。點選它，螢幕會顯示 6 位數代碼，在編輯器中輸入即可。系統會建立一個符合螢幕尺寸的新螢幕。
- **首次啟動精靈。**「你的面板」步驟會在 USB 面板旁列出 Wi-Fi 螢幕，各有一個**配對**按鈕。
- **命令列。**
  ```sh
  kiosko remote list
  kiosko remote pair <uid 或位址>
  ```
  `pair` 會要求輸入螢幕上顯示的代碼。

代碼只能嘗試一次，有效期限 2 分鐘。

## 方向

在 Kiosko 中該螢幕的卡片上設定：「橫向」或「直向」，「旋轉 180°」可上下翻轉。Kiosko 傳送的就是你在編輯器中看到的頁面，螢幕會自行旋轉，不增加負擔。若上下顛倒，請按「旋轉 180°」。以 Kiosko 的設定為準：螢幕每次連線時都會收到。

## 亮度與溫度

螢幕韌體 0.1.2 或更新版本時，螢幕卡片上有一個**亮度**滑桿（0–100%）。螢幕會記住它，沒有 Kiosko 時也一樣。未設定時使用螢幕自己的亮度：70%，或在其設定頁面中選擇的值。亮度越低，發熱越少。

卡片的狀態列還會顯示**晶片溫度**。它會高於室溫：這款晶片在 35–45 °C 左右屬於正常。

## 多台螢幕

逐一配對。每台螢幕都有自己的卡片、頁面和方向。在設定頁面為它們命名（*kitchen*、*desk*），方便區分。Kiosko 以每台螢幕的唯一 ID 追蹤它們，所以改名不會造成問題。它們的主機名稱是 `kiosko-<名稱>.local`。

## BOOT 按鈕

| 按法 | 作用 |
|---|---|
| 短按 | 已配對的螢幕在 2 分鐘內接受新的配對（或取消進行中的配對） |
| 按住 5 秒 | 忘記配對 |
| 按住 10 秒 | 忘記配對和 Wi-Fi，並重新啟動進入設定 |

按住按鈕時，螢幕會顯示經過的秒數。

## 更新韌體

在螢幕的卡片上：「更新韌體…」，然後選擇應用程式的 `.bin`（不是 `-full` 那個）。或使用命令列：

```sh
kiosko remote ota <螢幕> kiosko-screen-<版本>-waveshare-esp32c6-lcd-1.47.bin
```

螢幕會檢查映像檔並以它重新啟動。若新韌體無法連上 Wi-Fi，或之後 Kiosko 無法與它連線，螢幕會自動回復到先前的韌體。

## 重設與解除配對

- **從 Kiosko：** 在卡片上按「解除配對」，或執行 `kiosko remote unpair <螢幕>`。螢幕會忘記這個 Kiosko，之後可以重新配對。
- **在螢幕上：** 按住 BOOT 5 秒（只清除配對）或 10 秒（配對和 Wi-Fi）。
- **交給另一個 Kiosko：** 按一下 BOOT，然後在 2 分鐘內從另一個 Kiosko 配對。

## 疑難排解

- **在網路上找不到它。**
  - 確認螢幕有顯示 IP 位址。
  - 電腦與螢幕必須在同一個網路，且允許多點傳播（mDNS）。訪客網路、不同的 VLAN 和部分 Mesh 系統會阻擋它。
  - 執行 `kiosko doctor` 查看 Kiosko 收到了什麼。
  - 替代做法：在卡片上填入螢幕的位址（「位址」），或用位址配對：`kiosko remote pair 192.168.1.50`。
- **「這不是螢幕上的代碼」。** 每個代碼只能用一次。請重新開始：螢幕會顯示新代碼。
- **「錯誤代碼太多次」。** 每輸錯一次，螢幕要等更久才接受下一次嘗試（5 秒、10 秒、20 秒……最多 5 分鐘）。請稍候再試。
- **「已與另一個 Kiosko 配對」。** 在螢幕上按一下 BOOT，然後在 2 分鐘內配對。
- **「拒絕這個 Kiosko 的金鑰」。** 螢幕已重設或在別處配對。在卡片上按「重新配對」。
- **離線。** 螢幕沒有電源或不在 Wi-Fi 上。它一回來 Kiosko 就會自動重新連線，期間不會塞滿記錄。
- **畫面較慢。** 每張畫面解碼約需 60–90 毫秒，因此動態動畫大約只有 8–10 fps。靜態頁面不受影響。
