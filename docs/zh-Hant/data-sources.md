# 資料來源與設定檔

許多小工具不自己抓取資料，而是讀取**共用的資料來源**（`plugin/source`）：
一個來源只讀取一次，供所有使用它的小工具共用。新聞牌組（`news/deck`）、天氣、
你的行事曆、Home Assistant，都是資料來源。它們的設定在編輯器的
**設定 → 資料來源**中；每一行會顯示讀取間隔，以及上次讀取的結果。

資料來源只在已啟用螢幕上有小工具使用時才會執行。能發出警報的來源（天氣警報、
地震）也可以在沒有小工具時執行：**無需小工具也監看警報**。

## 設定檔：一個來源，多組設定

有些資料來源支援**設定檔**：同一個來源的多組具名設定，各有自己的選項，並且分開
讀取。一個螢幕顯示綜合新聞，另一個顯示科技新聞；一個方格顯示公司的 GitHub 帳號，
另一個顯示個人帳號。每個來源會說明是否支援；讀取本機唯一事物的來源（電池、感測器）
則不支援。

- **設定 → 資料來源**：支援設定檔的來源會以分頁顯示。**預設**是所有沒有另選的
  小工具所讀取的設定。**+ 設定檔**新增一個；每個分頁都可以重新命名、複製或刪除
  （會告訴你有幾個方格讀取它；刪除後這些方格改回讀取預設設定檔）。
- **在方格中**：檢視器會顯示**資料來源設定檔**。選擇一個，或選**新增設定檔…**：
  它會複製小工具目前讀取的設定檔、為它命名，並讓你直接在那裡修改選項
  （**編輯設定檔**）。
- **在情境頁面中**：針對帶設定檔的資料來源的*資料來源的值*條件有自己的**設定檔**（見[頁面](pages.md)）。

每個設定檔都有自己的資料、讀取間隔和狀態：在小工具的檢視器中，資料那一行會寫
`news/deck#tech`。讀取同一個設定檔的所有方格共用其選項。

### 依主題分的新聞

新聞牌組支援設定檔：「綜合」放各報頭版，「科技」放科技版（每家報紙每個版面都有
RSS），「體育」……每個設定檔各自歸併新聞，所以「4 家媒體報導」只在該設定檔內計算；
兩個設定檔都列了同一個訂閱源時，只會下載一次。

即使沒有設定檔，新聞小工具也可以用**主題**只保留部分新聞：在標題與導言中尋找的詞，
以逗號分隔，開頭加 `!` 表示排除（`颱風, 地震, !演習`）。不分大小寫與重音，
繁體與簡體皆可。

## 在設定檔案中

```json
{
  "sources": { "news/deck": { "feeds": [ { "name": "中央社", "url": "https://…" } ] } },
  "sourceProfiles": {
    "news/deck": {
      "tech": { "name": "科技", "options": { "feeds": [ { "name": "iThome", "url": "https://…" } ] } }
    }
  }
}
```

並在小工具中寫 `"profile": "tech"`。`sources["plugin/source"]` 永遠是預設設定檔：
沒有 `sourceProfiles` 的設定與以前完全相同。小工具的設定檔不存在時會讀取預設設定檔，
`kiosko config check` 也會提醒。

給外掛作者：在資料來源中宣告 `profiles: true`（見
[撰寫外掛](../plugins.md#shared-sources)）；小工具不必修改，會在
`ctx.sources["plugin/source"]` 找到該設定檔的資料，而 `ctx.profile` 會告訴來源
它正在讀取哪一個。
