# Wi-Fi 屏幕（ESP32）

> **新功能，实验性。** Kiosko 也能驱动使用 ESP32 的 Wi-Fi 小屏幕，运行 Kiosko
> 自己的开源固件。它们像任何副屏一样显示 Kiosko 的屏幕，可以放在家里任何地方。
> 本指南介绍如何使用；通信协议见 [remote-screen.md](../remote-screen.md)。

你将得到：

- **自动广播自己。** Kiosko 会自动在你的网络上找到它。
- **用屏幕上的代码配对。** 只有站在屏幕前的人才能配对，连接也经过加密。
- **自动重新同步。** 断电或 Wi-Fi 中断后，Kiosko 会重新连上，并在它恢复时立即发送当前画面。
- **任意方向**，竖放或横放，在 Kiosko 中设置。
- **可同时使用多台**，每台有自己的名称和页面。

## 需要什么

- 受支持的开发板。目前：**Waveshare ESP32-C6-LCD-1.47**（172×320）。之后会支持更多；固件已为此预留开发板层。
- 一根 USB-C 线，用于首次安装固件。之后通过 Wi-Fi 更新。
- 与运行 Kiosko 的电脑共用的 2.4 GHz Wi-Fi 网络，两者之间允许组播（mDNS）。

## 安装固件

**现成镜像。** [GitHub](https://github.com/kiosko-lcd/kiosko/releases/latest)
上的每个 Kiosko 版本都附带以下文件及其 SHA-256：

- `kiosko-screen-<版本>-waveshare-esp32c6-lcd-1.47-full.bin`：完整闪存镜像，通过 USB 写入新开发板。会清除开发板上原有的内容。
- `kiosko-screen-<版本>-waveshare-esp32c6-lcd-1.47.bin`：仅应用程序，用于从 Kiosko 或屏幕的设置页面更新。

写入完整镜像时，接上开发板，在 Docker 中使用 `esptool`（无需安装任何东西）：

```sh
docker run --rm -v "$PWD:/w" --device /dev/ttyACM0 espressif/idf:v5.5.5 \
  esptool.py --chip esp32c6 -b 921600 write_flash 0x0 /w/kiosko-screen-0.1.1-waveshare-esp32c6-lcd-1.47-full.bin
```

请使用开发板实际出现的端口（Linux 上可用 `ls /dev/serial/by-id/` 查看）。其他 `esptool` 或 Espressif 的网页烧录工具也可以。

**自行编译。** 在 [firmware/esp32-screen](../../firmware/esp32-screen) 中，一切都在 Docker 里运行：

```sh
./idf build           # build/kiosko_screen.bin
./idf flash           # 通过 USB
./idf backup old.bin  # 先备份开发板当前的闪存
```

**Linux 的 USB 权限。** 你的用户必须能打开串口。加入 `dialout` 组后重新登录：

```sh
sudo usermod -aG dialout "$USER"
```

## 首次启动与 Wi-Fi

如果没有保存 Wi-Fi，或 20 秒内无法连接，屏幕会开启自己的网络 `Kiosko-<名称>-setup`，并在屏幕上显示密码。

1. 用手机或笔记本连接该网络。
2. 设置页面会自动打开；如果没有，请访问 `http://192.168.4.1`。
3. 选择你的 Wi-Fi 网络并输入密码。也可以在这里为屏幕命名（`a-z`、`0-9`、`-`）并设置时区。
4. 保存。屏幕会重启并加入你的网络，随后显示它的名称、地址，以及“尚未配对：在 Kiosko 中添加”。

## 在 Kiosko 中添加

任选一种方式：

- **编辑器。**“屏幕 → 添加屏幕 → 检测副屏”。屏幕会出现在列表中。点击它，屏幕会显示 6 位数字代码，在编辑器中输入即可。系统会创建一个符合屏幕尺寸的新屏幕。
- **首次启动向导。**“你的副屏”步骤会在 USB 副屏旁列出 Wi-Fi 屏幕，各带一个**配对**按钮。
- **命令行。**
  ```sh
  kiosko remote list
  kiosko remote pair <uid 或地址>
  ```
  `pair` 会要求输入屏幕上显示的代码。

代码只能尝试一次，有效期 2 分钟。

## 方向

在 Kiosko 中该屏幕的卡片上设置：“横屏”或“竖屏”，“旋转 180°”可上下翻转。Kiosko 发送的就是你在编辑器中看到的页面，屏幕会自行旋转，不增加负担。如果上下颠倒，请点“旋转 180°”。以 Kiosko 的设置为准：屏幕每次连接时都会收到。

## 多台屏幕

逐一配对。每台屏幕都有自己的卡片、页面和方向。在设置页面为它们命名（*kitchen*、*desk*），方便区分。Kiosko 通过每台屏幕的唯一 ID 跟踪它们，所以改名不会造成问题。它们的主机名是 `kiosko-<名称>.local`。

## BOOT 按钮

| 按法 | 作用 |
|---|---|
| 短按 | 已配对的屏幕在 2 分钟内接受新的配对（或取消正在进行的配对） |
| 按住 5 秒 | 清除配对 |
| 按住 10 秒 | 清除配对和 Wi-Fi，并重启进入设置 |

按住按钮时，屏幕会显示经过的秒数。

## 更新固件

在屏幕的卡片上：“更新固件…”，然后选择应用程序的 `.bin`（不是 `-full` 那个）。或使用命令行：

```sh
kiosko remote ota <屏幕> kiosko-screen-<版本>-waveshare-esp32c6-lcd-1.47.bin
```

屏幕会检查镜像并用它重启。如果新固件无法连上 Wi-Fi，或之后 Kiosko 无法与其连接，屏幕会自动回滚到之前的固件。

## 重置与解除配对

- **从 Kiosko：** 在卡片上点“解除配对”，或运行 `kiosko remote unpair <屏幕>`。屏幕会忘记此 Kiosko，之后可以重新配对。
- **在屏幕上：** 按住 BOOT 5 秒（仅清除配对）或 10 秒（配对和 Wi-Fi）。
- **交给另一个 Kiosko：** 按一下 BOOT，然后在 2 分钟内从另一个 Kiosko 配对。

## 故障排除

- **在网络上找不到它。**
  - 确认屏幕显示了 IP 地址。
  - 电脑和屏幕必须在同一网络中，并允许组播（mDNS）。访客网络、不同的 VLAN 和部分 Mesh 系统会阻止它。
  - 运行 `kiosko doctor` 查看 Kiosko 收到了什么。
  - 替代做法：在卡片上填写屏幕的地址（“地址”），或按地址配对：`kiosko remote pair 192.168.1.50`。
- **“这不是屏幕上的代码”。** 每个代码只能用一次。请重新开始：屏幕会显示新代码。
- **“错误代码次数过多”。** 每输错一次，屏幕要等更久才接受下一次尝试（5 秒、10 秒、20 秒……最多 5 分钟）。请稍候再试。
- **“已与另一个 Kiosko 配对”。** 在屏幕上按一下 BOOT，然后在 2 分钟内配对。
- **“拒绝此 Kiosko 的密钥”。** 屏幕已重置或在别处配对。在卡片上点“重新配对”。
- **离线。** 屏幕断电或不在 Wi-Fi 上。它一恢复 Kiosko 就会自动重连，期间不会刷屏日志。
- **画面较慢。** 每张画面解码约需 60–90 毫秒，因此动态动画大约只有 8–10 fps。静态页面不受影响。
