# 数据源与配置

许多小组件不自己抓取数据，而是读取**共享的数据源**（`plugin/source`）：
一个数据源只读取一次，供所有使用它的小组件共用。新闻卡组（`news/deck`）、天气、
你的日历、Home Assistant，都是数据源。它们的设置在编辑器的
**设置 → 数据源**中；每一行显示读取间隔和上次读取的结果。

数据源只在已启用屏幕上有小组件使用时才运行。能发出警报的数据源（天气预警、地震）
也可以在没有小组件时运行：**无需小组件也监看警报**。

## 配置：一个数据源，多组设置

有些数据源支持**配置**：同一个数据源的多组命名设置，各有自己的选项，并且分别读取。
一块屏幕显示综合新闻，另一块显示科技新闻；一个格子显示工作的 GitHub 账号，
另一个显示个人账号。每个数据源会说明是否支持；读取本机唯一事物的数据源（电池、
传感器）则不支持。

- **设置 → 数据源**：支持配置的数据源以标签页显示。**默认**是所有没有另选的小组件
  读取的设置。**+ 配置**新增一个；每个标签页都可以重命名、复制或删除（会显示有几个
  格子读取它；删除后这些格子改回读取默认配置）。
- **在格子中**：检查器会显示**数据源配置**。选择一个，或选**新建配置…**：它会复制
  小组件当前读取的配置、为它命名，并让你直接在那里修改选项（**编辑配置**）。

每个配置都有自己的数据、读取间隔和状态：在小组件的检查器中，数据那一行写作
`news/deck#tech`。读取同一配置的所有格子共用其选项。

### 按主题的新闻

新闻卡组支持配置：“综合”放各报头版，“科技”放科技频道（每家媒体每个频道都有 RSS），
“体育”……每个配置各自归并新闻，所以“4 家媒体报道”只在该配置内计算；两个配置都列了
同一个订阅源时，只下载一次。

即使没有配置，新闻小组件也可以用**主题**只保留部分新闻：在标题和导语中查找的词，
用逗号分隔，开头加 `!` 表示排除（`台风, 地震, !演习`）。不区分大小写和重音，
繁体和简体均可。

## 在配置文件中

```json
{
  "sources": { "news/deck": { "feeds": [ { "name": "新华网", "url": "https://…" } ] } },
  "sourceProfiles": {
    "news/deck": {
      "tech": { "name": "科技", "options": { "feeds": [ { "name": "36氪", "url": "https://…" } ] } }
    }
  }
}
```

并在小组件中写 `"profile": "tech"`。`sources["plugin/source"]` 始终是默认配置：
没有 `sourceProfiles` 的设置与以前完全相同。小组件的配置不存在时会读取默认配置，
`kiosko config check` 也会提醒。

给插件作者：在数据源中声明 `profiles: true`（见
[编写插件](../plugins.md#shared-sources)）；小组件无需修改，会在
`ctx.sources["plugin/source"]` 找到该配置的数据，而 `ctx.profile` 告诉数据源
它正在读取哪一个。
