# @loksly/usb-ly

A Node.js driver for the Thermalright **LY** USB LCD panels (Trofeo Vision
9.16 and siblings, USB `0416:5408` / `0416:5409`), over libusb. No Python, no
`trcc`.

```js
import { LyPanel } from '@loksly/usb-ly';

const panel = await LyPanel.open({ serial: '202592047DAE' }); // or no serial: the first one
console.log(panel.info);          // { pm: 65, sub: 5, model: { width: 1920, height: 462, rotate: 180 }, … }
const kept = await panel.send(jpegBuffer); // false: the panel dropped it (too big)
await panel.close();
```

- **A frame is never silently lost.** `send` reads the panel's ACK: byte 8 is
  1 when it kept the frame and 2 when it dropped it (the limit is 511 871
  bytes). Without that, the write succeeds and the screen keeps the old picture.
- **Resend an unchanged frame every second or so**: the firmware shows the
  factory logo again after 2–3 s without one. That is the caller's job
  (Kiosko's `usb` driver does it).
- **A serial that is not found is an error**, never "another panel".
- `protocol.ts` is pure (no I/O) and its output is byte-identical to
  thermalright-trcc-linux 9.12 (the tests compare against vectors generated by
  `trcc` itself); `transport.ts` is the only part that touches libusb.

`usb` is an optional dependency: on Windows the panel needs the WinUSB driver,
on Linux a udev rule. See [docs/usb.md](../../docs/usb.md).

Not covered: other Thermalright protocols (SCSI, HID, 320×240), LED control.
